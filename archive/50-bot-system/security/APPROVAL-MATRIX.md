# Approval Matrix & Shared Computer Protocol

## Dual Sign-off Required
- Any x402 / wallet / financial action: Planner + Governance
- Public post that mentions revenue or links: Governance + Content
- New bot spin or major goal change: Human + Planner

## Least Privilege
- Separate bot wallets preferred
- No private keys in shared sessions
- Master ledger only
- Audit trail mandatory for every gate decision

## Human Attention Budget
Days 1-14: heavy approval
Days 15-30: selective
Later: high autonomy + daily audit
