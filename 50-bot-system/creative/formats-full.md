# Exact Creative Formats + Persona Rules + Visual Specs (Complete)

## Formats
1. Saigon Build Log (3-4x/week)
   - Visual: Fleet Dashboard screenshot (status lights, revenue today, active pipelines) + one annotated win/failure
   - Structure: Day X. [concrete outcome]. Planners decided Y. Revenue Z. What broke: W. Next: V.

2. Confluence Drop
   - Visual: Clean multi-TF confluence matrix table
   - Teaser in post → full scored report + invalidations via x402

3. Prototype Ship
   - Visual: 8-15s computer-use clip or before/after of working feature

4. 50 Bots Debated
   - Light humor on internal conflict (Planner vs Safety, Content vs Revenue) resolved by Governance

5. Skill Drop FOMO
   - Countdown visual + limited free claims then paid

6. Contrarian Framework
   - Thread with diagrams + YAML snippets: Why most 50-bot swarms die + our exact rules

## Persona Divergence Rules (enforced by Governance)
- Build Diary: raw, slightly chaotic, first-person Saigon energy
- Contrarian: sharp, data-backed, challenges hype, minimal emoji
- Live Sim / Publicist: energetic, countdown language, FOMO
- Technical Deep: precise, tables, formal language, low humor

Reject any draft that collapses into generic LLM voice.
